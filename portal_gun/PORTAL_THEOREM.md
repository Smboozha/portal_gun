## КРАТКОЕ РЕЗЮМЕ

Проход тела (макроскопического объекта) через портал r₀=0.1 м **исключён
всеми протестированными теориями** с разрывом 34–73 порядка. Это НЕ
«невозможно» как формула вежливости, а цепочка доказанных и проверенных
утверждений (квантовые неравенства + теорема Хохберга–Виссера + тесты
Солнечной системы + LIGO). Физика оставляет ровно два легальных канала:
**свет** (реален, строится из мусора) и **квантовый носитель через
атометровую электрослабовакуумную щель** ([ПОСТУЛАТ], ровно на границе QI).

## ЯДРО ЧЕСТНОГО ВЕРДИКТА (цепочка доказанных фактов)

```
QFТ-аксиомы (Вайтмен) ──→ QI (Форд–Роман):
      |ρ|_max(τ) = ħ/(8π²c³τ⁴)
        │
        ├─ устойчиво к: ускорению (A1), импульсам (A2),
        │   компактной топологии (B3), сжатым модам (B4),
        │   GUP-деформациям (C2)
        ▼
Макроскопическая отрицательная энергия НЕВОЗМОЖНА
        │
ОТО (теорема Хохберга–Виссера):
      проходимая горловина ТРЕБУЕТ нарушения NEC (B1)
        ▼
Для тела (проход ~6 нс): разрыв 70 порядков.
Модифицированная гравитация (единственный обход QI):
      убита солнечными тестами и LIGO (B2, C1)
```

**Вывод:** чтобы «портал для тела» стал физически возможным, потребовалось бы
наблюдаемое нарушение одного из этих звеньев. Ни одно из них не дало
расхождения ни в одном из 11 расчётов — это [ФИЗИКА], а не [ПОСТУЛАТ].

## ЧТО ФИЗИКА РАЗРЕШАЕТ РЕАЛЬНО

### 1. СВЕТ — РАЗРЕШЁН, строится сейчас
Фотон τ→0, QI не ограничивает. Световой портал из линз Френеля + перископ —
работающее устройство (`JUNK_PORTAL.md`, `portal_light_bridge.py`, тест пройден).

### 2. КВАНТОВЫЙ НОСИТЕЛЬ через атометровую щель — ровно на границе QI
a ≈ 10⁻¹⁸ м, τ = 3.2×10⁻²⁷ с:
`|ρ|_max(QI) = 4.7×10⁴⁴ ≈ ρ_need(0.1 м) = 4.8×10⁴⁴` (запас 0.98).
Это единственный легальный материальный канал. Требуемая инженерия —
электрослабовакуумный домен (энергии 100–250 ГэВ). [ПОСТУЛАТ] по реализации
границы, НЕ запрещён квантовым неравенством.

### 3. Формальная конструкция-призрак (требует новых принципов)
- С каскаду Планковских горловин (р₀→l_P: QI при t_P допускает ~10¹¹³ Дж/м³)
  физически легальна, но единая проходимая для тела метрика из каскада —
  не сконструирована (C2-совет) → [НОВЫЕ ПРИНЦИПЫ].
- Einstein-Aether / бumblebee (векторный сектор, без ограничения скорости
  гравитационных волн) — последний теоретически незакрытый угол (C1-совет) →
  [НОВЫЕ ПРИНЦИПЫ] (не протестирована, но и не даёт «сборки»: энергия
  горловины 10²⁰–10⁴³ Дж).

## КРИТЕРИИ РАЗБЛОКИРОВКИ (что должен показать эксперимент,
чтобы вердикт изменился)

1. **Нарушение QI макроскопически**: устойчивая отрицательная плотность энергии
   ВЫШЕ казимировского масштаба для данного окна (аномалия полости, сверх-
   Казимира в 1 мкм → 10⁻⁴ Дж/м³). Без этого нет экзотики → нет горловины.
2. **5-я сила с экранировкой**: отклонение от ньютоновской гравитации на
   масштабах 0.1–10 м ТОЛЬКО при локальных плотностях, недоступных тестам
   (Chameleon/Eöt-wash, атомная интерферометрия) — кандидат на скрытый сектор.
3. **Аномалия скорости гравитационных волн** |c_GW/c−1| ≫ 10⁻¹⁵ с анизотропией —
   сигнал векторного/NEC-сектора вне LIGO-предела.
4. **Локальный ложный вакуум**: работы с доменами p=−ρ на лабораторной шкале
   (конденсаты, сверхпроводящие аналоги Хиггса) — если ρ_домена достигнет
   ~10⁴⁴ Дж/м³ устойчиво, откроется классоворотный канал.

Ни один из критериев пока не достигнут; все находятся в зоне [ФИЗИКА]-проверки
и дешёвых 2026-лабораторных тестов (п.1–2 — уже можно измерять).

## ИТОГ ДЛЯ ПРОЕКТА

```
JUNK_PORTAL:  свет — ДА (реально, строим)
              квант (10⁻¹⁸ м) — РОВНО НА ГРАНИЦЕ QI  [ПОСТУЛАТ]
              тело — ИСКЛЮЧЕНО протестированной физикой (~70 порядков)
```

Портал для тела — не инженерная, а онтологическая развилка: требует либо
новой теории (п.1–4 выше), либо состоявшейся EW-щели для квантов. Оба пути
имеют измеряемые шаги. Световой портал — честный, собираемый сейчас результат.
