# R3 [ПОМ] — Сводка литературы: устойчивость f(T)-червоточины (ADM-энергия, моды, «струны нулевой энергии»)

Дата: 2026-09-07 · Автор: модель-помощник [ПОМ]
Статус: черновой обзор для главной модели [ОСН]; числа и формулы к перекрёстной сверке.

Целевая геометрия (Morris–Thorne):
  ds² = A(r)²dt² − B(r)²dr² − r²dΩ²,  A=1, B=1/√(1−b(r)/r).
В коде R1 принято b(r)=b0²/r (x этом заметно для пункта «ADM-энергия», см. §1).

## 1. ADM-энергия в телепараллельной теории

Установлено в TEGR (программа Малуфа):
- Плотность энергии гравитационного поля в TEGR задаётся через след кручения; интеграл по всему пространству для асимптотически плоских решений даёт стандартную ADM-энергию (J.W. Maluf, J.Math.Phys. 36 (1995) 4242, arXiv:gr-qc/9504010).
- Для Керра внутри внешнего горизонта энергия ≈ 2·M_ir (gr-qc/9608049); совпадает с результатом Брауна–Йорка в пределе малых a.
- Обобщение: телепараллельный 4-импульс совпадает с ADM везде, где ADM применим, при условии time gauge (J.B. Formiga, V.R. Gonçalves, PRD 106 044021 (2022), arXiv:2206.01322).

Важно для f(T):
- В f(T)-гравитации ADM-масса, измеренная по асимптотике метрики, НЕ обязана совпадать с GR-значением при той же константе связи.
- Показательный результат: Born–Infeld f(T) — ADM-масса растёт с параметром α; угол отклонения света, записанный ЧЕРЕЗ ADM-массу, совпадает с GR (K. Jusufi, S. Capozziello, S. Bahamonde, M. Jamil, EPJC 82 1018 (2022), arXiv:2205.07629). → Практический вывод для R4: все наблюдательные предсказания переписывать через измеряемую M_ADM, а не через «сырые» параметры модели.
- «Dark wormhole» (Z.-F. Mai, H. Lu, PRD 95 124024 (2017), arXiv:1704.05919): пространственная секция как у Эллиса, но −g_tt меняется от 0 до 1 — сигнал необратимо краснеет; асимптотика та же, что у Шварцшильда. Предостережение: не всякая f(T)-червоточина асимптотически «нормальная».

Конкретика для Morris–Thorne (проверить численно):
- b(r)=b0 const: асимптотическое поведение g_tt≈1, g_rr≈1+b0/r → ADM-масса M≈b0/2 (классика M.T.==Моррис–Торн, Am.J.Phys. 56 (1988) 395).
- b(r)=b0²/r (вариант из R1): g_rr≈1+b0²/r², т.е. поправка ~1/r² БЕЗ члена 1/r → M_ADM=0 (безмассовая/«космическая» ветвь). Это известная тонкость: «масслесная червоточина» (аналог Эллиса, «филиппсовая» семья).
- ПЕРЕКРЁСТНАЯ СВЕРКА для [ОСН]: посчитать M_ADM двумя независимыми способами — (i) коэффициент при 1/r в g_tt/g_rr; (ii) интеграл Малуфа ∫(след кручения) по Σ. Для b0=10 см и b=b0²/r обе модели обязаны получить ~0.

## 2. «Струны нулевой энергии»

Наиболее точное отождествление термина (телепараллельная литература):
- J.W. Maluf, A. Kneip, J.Math.Phys. 38 (1997) 458, arXiv:gr-qc/9505008: энергия конических дефектов в TEGR.
  - Дисклинация (= космическая струна): стандартная энергия на единицу длины.
  - Чистая дислокация (винтовая/краевая, дефект кристаллического типа): ПОЛНАЯ гравитационная энергия = НОЛЬ. Это и есть «струна нулевой энергии».
- Следствие для теорий: в TEGR топологический дефект-дислокация может нести ноль полной энергии; поверхность with nol=0 в f(T) может быть поддержана «геометрией» без экзотического источника (см. §3c).

Если в R3 имеется в виду другое («струны на горловине», Nambu–Goto поверхность, «космическая струна как оболочка горловины») — это НЕ отчётливо в литературе по f(T); укажите явно, какое определение используем. [Честная неоднозначность — фиксирую в отчёте.]

## 3. Устойчивость / моды — что делает литература

(a) Равновесие по TOV (самый распространённый, но это НЕ динамическая устойчивость):
- Проверяется баланс сил: гидростатическая + анизотропная + гравитационная компоненты (обобщённое TOV-равновесие). Используют почти все статьи по f(Q)/f(T,𝒯)-червоточинам: G. Mustafa et al., Ann.Phys. 437 (2022) 168751 (arXiv:2112.15112); O. Sokoliuk et al., Ann.Phys. 443 (2022) 168968 (arXiv:2201.00743); Z. Hassan et al., EPJC 82 1116 (2022) (arXiv:2207.09945); A. Rizwan-P.K. Sahoo пл. (arXiv:2410.05348).
- Вывод для отчёта: «устойчиво по условию равновесия» ≠ «динамически устойчиво». Слабые места: не учитывает времени.

(b) Квазинормальные моды (QNM) — прямой путь к «модам»:
- M.M. Rizwan, Z. Hassan, P.K. Sahoo, A. Övgün, EPJC 84 1132 (2024), arXiv:2410.05348 (f(T,𝒯), Casimir+GUP, zero tidal force): скалярные, электромагнитные, аксиально-гравитационные и дираковские возмущения; спектр из 3-го порядка ВКБ; также даны активная масса и полная гравитационная энергия.
- Рецепт общий (для нашей R3): свести к одномерному уравнению Шрёдингеру φ″+(ω²−V_eff)φ=0 с эффективным потенциалом Редже–Уилера от b(r), A(r); ВКБ для ω. Для f(T) с A=1, b=b0²/r потенциал V_eff(u)=... считается в коде и даёт (im ω) демпфирование. В литературе полноценный QNM именно для чистой f(T)-червоточины — НЕ найден: это наш вклад.

(c) Устойчивость за счёт дополнительных степеней свободы (геометрическая):
- V. De Falco, S. Capozziello, PRD 108 104030 (2023), arXiv:2308.05440: общие ограничения (flaring-out + NEC) для f(R), f(T), f(Q); при доп. степенях свободы возможны устойчивые и проходимые червоточины БЕЗ экзотического источника (всё берёт на себя геометрия). Таблица ограничений — готовый чек-лист для R3.

(d) Тонкие оболочки (Darmois–Israel):
- Классический путь устойчивости в GR; в f(T) полноценные junction-условия строгих тонких оболочек проработаны скупо (эффект: в нековариантной f(T) с диагональной тетрадой выбор тетрады меняет результат). Для нашего случая b=b0²/r без внешнего спивания не обязателен, но если фиксируем внешний Шварцшильд — требуется аккуратность.

(e) Мод-содержимое f(T) (физ. значимость «доп. скаляра»):
- Гравитационные волны в f(T) несут 3 поляризации: 2 тензорные + 1 скалярно-дыхательная (обзоры: S. Bahamonde et al., Rep.Prog.Phys. 86 026901 (2023), arXiv:2106.13793; Y.-F. Cai, S. Capozziello, M. De Laurentis, E.N. Saridakis, Rep.Prog.Phys. 79 (2016) 106901, arXiv:1511.07586).
- Именно скалярная степень f(T) берёт на себя «экзотическую» поддерживающую роль материи — ключевое следствие для R2/R3.

Известные GR-теоремы (контекст):
- Червоточина, пропущенная NEC-нарушающей материей, линейно неустойчива в GR; ANEC + топологическая цензура запрещают «просачивание». → В f(T) вопрос «динамическая устойчивость при поддержке торсионным скаляром» в литературе ОТКРЫТ. Честно фиксируем как нерешённое.

## 4. Энергетические условия (мостик к R2)

Канонические результаты:
- C.G. Böhmer, T. Harko, F.S.N. Lobo, PRD 85 044033 (2012), arXiv:1110.5756: статичные SSS-червоточины в f(T) с НЕдиагональной тетрадой могут удовлетворять WEC/NEC во всей области — «классика», осн. результат: f(T) способна снять требование экзотики.
- M. Jamil, D. Momeni, R. Myrzakulov, EPJC 73 2267 (2013), arXiv:1212.6017: для изотропного давления и баротропного EoS NEC удовлетворён; для анизотропного случая — нарушается. → Семейство f(T) и EoS надо сканировать вместе (наш R2).
- R.-H. Lin et al., arXiv:1906.10323: неминимальная связь материи и кручения: NEC выполнен только близко к горловине; «бесконечная» асимптотически плоская червоточина не выходит → нужен конечный внешний регион (спинка). Совместимо с (d).

Квантовое ограничение на толщину слоя экзотики:
- L.H. Ford, T.A. Roman (PRD 53 (1996) 5496 и предшествующие): квантовые неравенства ограничивают интеграл отрицательной энергии по светоподобной мировой линии. Для b0=10 см это требует ОЧЕНЬ тонкого слоя экзотики или его отсутствия — прямое указание на то, что в f(T) экзотика должна заменяться геометрией. ## 5. Что открыто (для отчёта R5 — «что не доказано»)

1. Полный линейный модовый анализ чистой f(T)-червоточины (A=1, b=b0²/r) — в литературе не сделан → наш вклад [ОСН]+[ПОМ].
2. Строгие распределённые junction-условия f(T) для тонких оболочек — литература скупая и чувствительна к выбору тетрады (диагональная vs. недиагональная).
3. Смысл «струн нулевой энергии» неоднозначен (двойная дислокация ТЭГР vs. струны горловины) — зафиксировано, см. §2.
4. ADM-масса f(T)-червоточины и согласованность с наблюдательными параметрами (Sgr A*) — частично закрыто для Born–Infeld (arXiv:2205.07629), не закрыто для общих f(T).
5. Динамическая (не равновесная) устойчивость — открытый вопрос.
