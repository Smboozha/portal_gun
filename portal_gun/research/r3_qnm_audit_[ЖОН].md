## 2. НАЙДЕНО: пропущенный вклад в эффективный потенциал ⚠️

План [ОСН] (STATUS.md): «V_eff(u) от b(r), A(r)». Попытка взять `V = l(l+1)/r²` (A=1) **неверна** для нашей геометрии.

Вывод [ЖОН] (hand + sympy, независимо):
```
ds² = −dt² + (1−b0²/ρ²)^{-1}dρ² + ρ²dΩ²,  ρ=areal radius
тортоида r*: ρ = √(r*²+b0²)
скаляр (минимально связанный, l-гармоника), редукция χ=ρ·φ:
   конформный вклад ρ''/ρ ДОБАВЛЯЕТСЯ:
   V(r*) = l(l+1)/ρ² + ρ''/ρ
        = [l(l+1)(r*²+b0²) + b0²]/(r*²+b0²)²
```
Следствия:
1. **l=0 здесь не «нет мод»**: монополь имеет барьер `V=b0²/ρ⁴≠0` — у Ellis-червоточины s-волновые QNM существуют (классический факт для drainhole).
2. Любой расчёт с `l(l+1)/r²` без `ρ''/ρ` даёт НЕ тот спектр. Нужно пересчитать.
3. Форма `V(r*)` совпадает с drainhole-Эллиса (в другом координатном представлении это та же метрика), поэтому литературные цифры ДРЕНХОЛА применимы напрямую — но только если мы считаем ту же V.

## 3. Предварительный независимый численный скан (дешёвый, ~13 с)
Метод: прямое резонансное shooting (RK4, N=1600, R=80, BC ψ′−iωψ=0 на +∞), чётные/нечётные моды, комплексный Ньютон. V корретная (§2).

Старшие «кандидаты» для l=0,1,2 (НЕ отождествлены как фундаментальные — см. оговорку):
```
l=0 even: 0.388−0.106i, 0.505−0.108i, 0.544−0.109i …
l=1 even: 0.410−0.048i, 0.489−0.050i, 0.567−0.052i …
l=2 even: 0.390−0.041i, 0.508−0.044i, 0.548−0.045i …
```
ОГОВОРКА: при стрельбе с малой отсечкой R появляются «боксовые» артефакты (семейства с почти постоянной Im по всему Re — МОЙ отсчёт это показал). Поэтому величина |Im| и сам выбор фундаментальной моды НЕ окончательны. Для чистого спектра нужен ВКБ-3 (Ийер-Уилл/Конопля) по исправленной V или метод Лизнера (длинная поглощающая сетка). **Назначено [ТР3]**.
 
## 4. Сверка цифр 0.54 / −0.07 — НЕ ЗАКРЫТА
- Rizwan 2410.05348 (EPJC 84 1132, QNM 3-го порядка ВКБ) — про **Casimir+GUP** wormhole в f(T,𝒯), НЕ про чистую Ellis/MT-флейринг. Как «источник» для 0.54/−0.07 он не подходит сам по себе.
- Для чистого drainhole/флейринг Ellis в GR цифры Re≈0.54/Im≈−0.07 **должны быть подтверждены конкретным источником** (Ellis-QNM-статья: например, серия Konoplya-и др. по QNM drainhole). **[ПОМ]: дать точную ссылку с таблицей.**
