# R3-TH-A3 — Энергия Казимира на тороидальном гиперболоиде

**Агент-3 (Геометр-квантовик)** · файл `r3_casimir_torhyp_a3.py` · JSON `r3_casimir_torhyp_a3_values.json`

## 1. Постановка и модель геометрии

Тороидальный гиперболоид — тор (ось радиуса R) с гиперболическим сечением (параметр a, кривизна K = −1/(Ra)):

$$x(u,\theta) = (R + a\cosh\theta)\cos u, \quad y(u,\theta) = (R + a\cosh\theta)\sin u, \quad z(u,\theta) = a\sinh\theta$$

$$u \in [0,2\pi), \quad \theta \in [-\theta_{\max},\,\theta_{\max}], \quad \theta_{\max} = 1.0\ \text{rad} \tag{1}$$

Метрика:

$$ds^2 = a^2\,d\theta^2 + (R + a\cosh\theta)^2\,du^2 \tag{2}$$

Главные кривизны: $\kappa_1 = 1/(R + a\cosh\theta)$ (вдоль оси тора), $\kappa_2 = -a/(R + a\cosh\theta)$ (сечение). Гауссова кривизна $K = -1/[a(R + a\cosh\theta)]$ — всюду отрицательная.

Лапласиан на поверхности:

$$\Delta = \frac{1}{a^2}\frac{\partial^2}{\partial\theta^2} + \frac{\sinh\theta}{a(R + a\cosh\theta)}\frac{\partial}{\partial\theta} + \frac{1}{(R + a\cosh\theta)^2}\frac{\partial^2}{\partial u^2} \tag{3}$$

Разложение $u \to e^{imu}$ сводит задачу к 1D-ODE в $\theta$:

$$X'' + \frac{\sinh\theta}{R + a\cosh\theta} X' - \frac{m^2 a^2}{(R + a\cosh\theta)^2} X = -\mu X \tag{4}$$

Краевые условия: **Dirichlet** на $\theta = \pm\theta_{\max}$ (стенки «разреза»).

## 2. Численный метод

Безразмерная форма: $\tilde{R} = R/a$. Сетка $\theta_j = -\theta_{\max} + jh$, $h = 2\theta_{\max}/(N+1)$.

Матрица безразмерного Лапласиана $\tilde{L} = a^2\Delta$:

- Диагональ: $\frac{2}{h^2} + \frac{m^2}{(\tilde{R} + \cosh\theta_j)^2}$
- Над-/поддиагональ: $-\frac{1}{h^2} \mp \frac{\sinh\theta_j}{h(\tilde{R} + \cosh\theta_j)}$

Собственные значения $\mu_{m,n}$ — безразмерные. Физические частоты: $\omega = \sqrt{\mu}/a$.

Параметры: **N=600** узлов, **m=0..20**, всего **12 553** собственных значения.

## 4. Регуляризация и что именно вычитается

Энергия с энергетическим обрезанием:

$$E(\varepsilon) = \tfrac12 \sum_{m,n} \omega_{m,n}\, e^{-\varepsilon\omega_{m,n}} \tag{5}$$

Расходящаяся часть выделяется по heat-kernel разложению. Вычитается **плоский УФ-член площади**:

$$E_{\rm cas} = -\frac14 \int_0^\infty \frac{dt}{t^{3/2}}\left[\operatorname{Tr}\left(e^{-t\Delta}\right) - \frac{A}{4\pi t}\right] \tag{6}$$

где $A = 4\pi^2 a R(R/a + \cosh\theta_{\max})$ — площадь поверхности.

**Что удалено (честная подпись):** из следа теплового ядра вычитается плоский УФ-член $A/(4\pi t)$, где $A$ — полная площадь поверхности. Это эквивалентно вычитанию ведущей расходимости $\sim A/(4\pi\varepsilon^2)$ энергетического обрезания. Кривизненные члены (порядка $K$) не вычитаются — они и составляют физический ответ.

Безразмерная константа:

$$C = \sqrt{\pi} \int_0^\infty \frac{ds}{s^{3/2}}\left[\sum_{m,n} e^{-s\mu_{m,n}} - \frac{\tilde{A}}{4\pi s}\right] \tag{7}$$

где $\tilde{A} = 4\pi^2 \tilde{R}(\tilde{R} + \cosh\theta_{\max}) = 399.0$.

## 7. Вердикт

**При $a = 0.1$ м, $R = 0.25$ м:**

$$\boxed{C = -37\,334\,701}$$

$$E_{\rm cas} = -1.180 \times 10^{-17}\ \text{Дж}$$

$$\rho_{\rm cas} = -4.330 \times 10^{-17}\ \text{Дж/м}^3$$

**Знак: ОТРИЦАТЕЛЬНЫЙ (притягивающий).** Тороидальный гиперболоид при $a=0.1$ м, $R=0.25$ м даёт отрицательную энергию Казимира ($\rho < 0$). Это поддерживает гипотезу о возможности энергетической kondensации / «чёрных дыр на метаматериалах» на седловой поверхности.

Контраст с псевдосферой ($C = +22\,822$, отталкивающая): топология тора (периодичность по $u$) принципиально меняет знак. На псевдосфере УФ-доминирование даёт $C > 0$; на тороидальном гиперболоиде доминирование кривизненных мод даёт $C < 0$.

**Пределы** ($E = C\hbar c/a$, $C < 0$):
- $a \to 0^+$: $E \to -\infty$ (расходится, притягивание).
- $a \to \infty$: $E \to 0^-$ (стремится к нулю со стороны $-$).
