# R3-PS-A3 — Энергия Казимира на псевдосфере (K=−1/a²)

**Агент-3 (Геометр-квантовик)** · файл `r3_casimir_pseudosphere_a3.py` · JSON `r3_casimir_pseudosphere_a3_values.json`

## 1. Постановка и модель геометрии

Стоячая геометрия — псевдосфера (гиперболическая крышка радиуса `a`, постоянная кривизна K = −1/a²). 2D-полость = геодезический диск на H²:

$$ds^2 = a^2\left(d\chi^2 + \sinh^2\chi\, d\phi^2\right), \qquad \chi\in[0,R],\ R=1.0\ (\text{ед. }a),\ \phi\in[0,2\pi) \tag{1}$$

Лапласиан:

$$\Delta = a^{-2}\left(\partial_\chi^2 + \coth\chi\,\partial_\chi + \sinh^{-2}\chi\,\partial_\phi^2\right) \tag{2}$$

Разложение $\phi\to e^{im\phi}$ сводит задачу к 1D-радиальному ODE:

$$X'' + \coth\chi\, X' - \frac{m^2}{\sinh^2\chi}\, X = -\lambda X \tag{3}$$

Краевые условия: регулярность у центра $\chi=0$, **Dirichlet** на стенке $\chi=R$.

## 2. Численный метод

κ-дискретизация: $\chi_i = i\,\Delta\chi$, $\Delta\chi = R/(N{+}1)$, конечные разности 2-го порядка (numpy). Матрица $(-L_m)$ трёхдиагональна, собственные значения $\lambda_{m,n}\ge0$ считались через `scipy.linalg.eigh_tridiagonal`. Параметры рабочего прогона: **N=600** узлов, **m=0..200**, всего **120 425** собственных значений. (Сравнение N=400/600 и m=60/120/200 — см. §5, сходимость.)

Мода 2D-полости (Бойер-схема): $\omega^2 = \lambda_{m,n}/a^2$.

## 3. Энергетическое обрезание и что именно вычитается

Энергия с энергетическим обрезанием:

$$E(a;\varepsilon) = \tfrac12 \sum_{m,n} \omega_{m,n}\, e^{-\varepsilon\omega_{m,n}} \tag{4}$$

Расходящаяся часть выделяется по heat-kernel разложению: ведущая плоская УФ-расходимость площади $A = 2\pi a^2(\cosh R-1)$ даёт вклад $A/(4\pi t)$ в trace, что в интегрировании эквивалентно вычитанию члена $\propto a^{-2}\varepsilon^{-2}$. Вычитание реализовано как (heat-kernel регуляризация):

$$E_{\rm cas}(a) = -\frac14 \int \frac{dt}{t^{3/2}}\left[\operatorname{Tr}\left(e^{-t\Delta}\right) - \frac{A}{4\pi t}\right] \tag{5}$$

**Что вычитается (честная подпись):** из следа вычитается плоский УФ-член площади $A/(4\pi t)$, где $A=2\pi a^2(\cosh R-1)$ — геодезическая площадь диска. Другими словами, вычитается ведущая $\sim a^{-2}\varepsilon^{-2}$ расходимость энергетического обрезания с коэффициентом $A/(4\pi)$. Кривизнные (порядка $K$) члены не вычитаются — они и составляют физический ответ.

## 6. Модель объёма для ρ

- Площадь диска: $A = 2\pi a^2 \sinh^2 R$ … $A/a^2 = 8.678$
- Модель полости: диск толщиной $t=2\pi a$ (wrap по $\phi$), объём
  $$V = A\cdot t = 4\pi^2 a^3 \sinh^2 R,\qquad V/a^3 = 54.524$$
  (зафиксировано: толщина = длина окружности $2\pi a$ — фиксирую модель явно).

## 8. Выводы (обязательные)

**(i) Знак E_cas при a=0.1 м:** **ПОЛОЖИТЕЛЬНЫЙ** (ρ>0, отталкивание).
$$C = +22\,822,\qquad E_{\rm cas}(0.1\,\text{м}) = +7.215\times10^{-21}\,\text{Дж},\qquad \rho_{\rm cas} = +1.323\times10^{-19}\,\text{Дж/м}^3.$$
Это означает: **гипотеза «на седловой поверхности ρ<0» в рамках данной минимальной модовой модели НЕ подтверждается** — знак обратный.

**(ii) Пределы из E = Cħc/a (C>0):**
- a→0⁺: E→+∞ (расходится, знак +).
- a→∞: E→0⁺ (стремится к нулю со стороны +).

**Честная оговорка (регуляризацией не жонглирую):** результат получен на конечно-обрезанной модовой сумме (m≤200, N=600) с вычитанием только плоского УФ-члена площади. Значение C ~2.3×10⁴ — **систематически большое и положительное**; доминирующая УФ-расходимость при таком sequential-обрезании не позволяет извлечь «наивный» отрицательный вклад. Итог: в данной минимальной реализации **C > 0**.
