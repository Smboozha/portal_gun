# R3-ADM [ЖОН] — Аудит: судьба метода Малуфа при диагональной тетраде (A=1)

Дата: 2026-09-07 · Автор: координатор [ЖОН]
Статус: ЛОГИКА ПРОВЕРЕНА, РЕКОМЕНДАЦИЯ ВЫДАНА

## 1. Что утверждалось
[ОСН]: `tetrad_core.S_worm_numeric` даёт `S^{01}_0 = −1/r` при A=1, C=r «для любой B», и поток Малуфа расходится.

## 2. Независимая проверка [ЖОН]

### 2.1 Символьный результат (свой, не из кода [ОСН])
```
S^{01}_0 = −C'(r)/C(r) − A'(r)/(2A(r))
```
Для A=1, C=r: `S^{01}_0 = −1/r`. **Подтверждено.**

### 2.2 Проверка независимости от формы червоточины (численно)
| r | ellis | const |
|---|-------|-------|
| 0.5 | −2.0 | −2.0 |
| 1.0 | −1.0 | −1.0 |
| 2.0 | −0.5 | −0.5 |
Одинаково для обеих форм b(r) → компонента суперпотенциала `S^{01}_0` **не чувствительна к b(r) вообще**. Это определяющий признак: перед нами калибровочно/координатный вклад, не физический (физическая масса обязана зависеть от b).

### 2.3 Расходимость интеграла Малуфа
Малуфовская энергия = поверхностный интеграл по r→∞ от выражения, содержащего `S^{01}_0` × универсальный объёмный множитель. Элемент 2-сферы `d²Σ ~ r²dΩ`; `S^{01}_0 ~ 1/r` ⇒ подынтегральное `~ r²·(1/r) = r` ⇒ интеграл **растёт линейно с радиусом отсечки**. Никакой «нулевой/конечной» энергии в этом канале не получить без явной регуляризации/вычитания.

## 3. Почему это артефакт, а не масса
1. Компонента `S^{01}_0` зависит только от **тетрады** {A,C} и их производных, а не от функции `b(r)`. Масса обязана «знать» о b(r).
2. Для диагональной тетрады с A=1 торсионный скаляр T и суперпотенциал содержат чисто координатный (J-нетривиальный) вклад от `1/r` геометрической структуры вейтценбёка — классический случай «bad tetrad» (Tamanini–Boehmer, arXiv:1204.4593; см. R2-файлы [ПОМ]).
3. «Струны нулевой энергии» Малуфа–Кнейпа (gr-qc/9505008) касаются **дислокаций** (винтовых дефектов) — не нашего диагонального вейтценбёка. Прямоих аналогов тут нет: это другой топологический класс.

## 4. Вывод-рекомендация [ЖОН]

**Метод Малуфа для диагональной тетрады с A=1 в текущем виде НЕ является валидным измерением ADM-массы.**

Варианты (выбрать один, не смешивать):
1. **Основной метод → коэффициент при 1/r в g_μν** (гравитационная масса из асимптотики метрики):
   - ellis (b=b0²/r): `g_rr = 1+b0²/r²+…` — член 1/r **отсутствует** ⇒ **M_ADM = 0** (подтверждено рядом выше).
   - const (b=b0): `g_rr = 1+b0/r+…` ⇒ коэффициент b0 ⇒ **M_ADM = b0/2** (классика Morris–Thorne).
   Это согласуется с r3_lit_review_helper.md §1.
2. **Малуфа — только как калибровочно-чувствительная проверка**, с явной пометкой «gauge-degenerate» при диагональной тетраде; либо пересчитать в недиагональной «good»-тетраде (ft2_goodtetrad_*), где T и суперпотенциал калибровочно согласованы (значения T_good на порядки меньше и дают GR-лимит → там Малуф осмыслен).

## 5. Что закрыто / что открыто
- ✅ Диагноз **«S^{01}_0=−1/r — gauge-артефакт, интеграл расходится»** подтверждён.
- ✅ Численный факт M_ADM(ellis)=0, M_ADM(const)=b0/2 по коэффициенту 1/r подтверждён в двух формах b(r).
- ⬜ ОТКРЫТО: вычисление интеграла Малуфа в «good»-тетраде (это закрывает R3-пункт ADM полностью). Назначается [ОСН].
