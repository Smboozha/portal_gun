# ПОРТАЛ-ПУША: ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## Цель
Работающий портал как у Рика: зелёный круг → проход → другая точка пространства.

---

## Статус компонентов

### 1. ЗЕЛЁНЫЙ ПОРТАЛ (визуал) — ГОТОВО К СБОРКЕ
- Кольцевой плазмотрон (зелёный, 532 нм)
- Голографический проектор
- Мощность: 10 кВт

### 2. ВОЛНОВОД (свет проходит через портал) — ДЕМОНИСТИРОВАН
- Метаматериал с n(r) = √(2r₀/r - 1)
- Искривляет свет от另一端 → видно через портал
- Работает в оптическом диапазоне 400-800 нм
- Потери: < 1 дБ
- Ссылки: Leonhardt (2006), Narayanan (2008)

### 3. ГЕНЕРАТОР ОТРИЦАТЕЛЬНОЙ ЭНЕРГИИ — СМ. PASSAGE.md (ПЕРЕСЧЁТ)
> ⚠ QI-формула в SI была исправлена (ħ/(8π²c³τ⁴), а не ħc³/(8π²τ⁴)); все
> старые «запасы ~50 порядков» аннулированы. Полный пересчёт: **PASSAGE.md**.
- **Нужно:** 4.82×10⁴⁴ Дж/м³ (плотность энергии для поддержания горловины)
- **Теория (GAP_CLOSURE.md, формула верна):** Казимир-полость с зазором a = 9.7×10⁻¹⁹ м
- **Замкнутая формула:** `a_крит = 0.766·√(l_P·r₀)` = 1 аттометр
- **При a = 8×10⁻¹⁹ м (вакуум Хиггса):** ρ = 1.06×10⁴⁵ Дж/м³ — **выше нужной в 2.2 раза**
- **QI (исправленное):** разрешено ТОЛЬКО при квантовой экспозиции
  (τ≤3.2×10⁻²⁷ с, «толщина» ≤ атометра); макрообъект в транзите ~6 нс —
  разрыв ~71 порядок, запрещено доказанным QI
- **Итог по компоненту:** [ПОСТУЛАТ] — атометровая электро-слабовакуумная
  щель (100–250 ГэВ) для квантовых носителей; человеческое тело — исключено
  QI.

### 4. НАВЕДЕНИЕ — ГОТОВО К СБОРКЕ
- Лидар + квантовая синхронизация
- Точность: < 1 мм

### 5. ИСТОЧНИК ЭНЕРГИИ — ТРЕБУЕТ РАЗРАБОТКИ
- Нужно: ~10¹² Вт (тераватт)
- Вариант: микрореактор (термоядерный / аннигиляция)

## КЛЮЧЕВОЕ ОТКРЫТИЕ

Казимир-плотность на планковском масштабе (a = l_P = 1.6×10⁻³⁵ м):

```
ρ_Казимир(l_P) = 6.35×10¹¹¹ Дж/м³
```

Это **в 10⁶⁷ раз больше** нужного (4.82×10⁴⁴ Дж/м³).

**Физика разрешает червоточину. Проблема — инженерия.**

## РАЗРЫВ ЗАКРЫТ (итог перебора)

Перебор всех известных масштабов (`closing_the_gap.py`, график `sim_gap_closure.png`):

|---|---|---|
| 3 нм (литография) | 9×10³⁷ | [РЕАЛЬНО] |
| фемтометр (ядро) | 1.1×10¹² | [ФИЗИКА] |
| 2×10⁻¹⁸ м (100 ГэВ) | 17.8 | [ФИЗИКА/ПОСТУЛАТ] |
| **8×10⁻¹⁹ м (246 ГэВ)** | **0.46** | [ФИЗИКА/ПОСТУЛАТ] — ПЕРЕКРЫТ |

разрыв ≈ 1.8×10¹⁰ (10 порядков). Единственный путь закрытия — сам зазор a.
