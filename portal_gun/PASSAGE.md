## ⚠ CORRECTION — ошибка в прежней QI-формуле (обязательно к прочтению)

В более ранних материалах (`GAP_CLOSURE.md`, `FINAL_REPORT.md`) квантовое
неравенство Форда–Романа записывалось в SI-виде

```
|ρ|_max = ħc³ / (8π² τ₀⁴)      ← ОШИБКА
```

Правильный SI-вид (перевод из натурной формы `|ρ| ≤ 1/(8π²τ⁴)` через
`ρ_SI = ρ_натур · ħc` и `τ_натур = c·τ_SI`):

```
|ρ|_max(τ) = ħ / (8π² c³ τ⁴)   [Дж/м³]      ← ВЕРНО
```

Разница — множитель `c⁶ ≈ 7.0×10⁴⁹`. Ошибочный вариант **завышал** допуск
квантового неравенства на ~50 порядков, из-за чего «закрытие разрыва до 1
порядка» и «импульсный режим» оказались артефактами.

**Тройная проверка верной формулы:**
1. Размерность: `ħ/(c³τ⁴)` = `M/(L·T²)` = Дж/м³. Совпадает.
2. CGS-сверка: из натурной `1/(8π²τ⁴)` следует SI-вид `4.96×10⁻⁶²/τ⁴`;
   совпадение до 4 знаков.
3. Казимир между пластинами на зазоре 1 мкм: `ρ_C = 4.33×10⁻⁴ Дж/м³`,
   при окне `τ = a/c` граница QI = `4.00×10⁻⁴`. Отношение **1.08** —
   статический Казимир сидит ровно на границе QI, как и заявляли Форд–Роман.

**Вывод:** все «запасы 50 порядков» из прежних файлов аннулированы.
Честные разрывы и вердикты — ниже.

## 1. Реструктурные числа (правильная QI)

| Объект | Окно τ | |ρ|_max(QI) | Нужно ρ_need | Разрыв |
|---|---|---|---|---|
| r₀ = 0.1 м, экспозиция r₀/c | 3.34×10⁻¹⁰ с | 4.0×10⁻²⁴ | 4.8×10⁴⁴ | 1.2×10⁶⁸ |
| r₀ = 1 м, экспозиция r₀/c | 3.34×10⁻⁹ с | 4.0×10⁻²⁸ | 4.8×10⁴² | 1.2×10⁷⁰ |
| Человек в транзите (L/c) | 6×10⁻⁹ с | 3.8×10⁻²⁹ | 4.8×10⁴² | **1.3×10⁷¹** |
| Квантовая экспозиция (EW) | 3.2×10⁻²⁷ с | 4.7×10⁴⁴ | 4.8×10⁴⁴ (r₀=0.1 м) | **≈1.0** |
| Свет (фотон) | τ→0 | →∞ | — | легально всегда |

### Ключевое совпадение (уже независимо, не артефакт)
Максимально легальная «толщина» области отрицательной энергии, способной
нести плотность ρ_need:

```
r₀ = 0.1 м :  c·τ_legal = (4.957e-62 / ρ_need)^{1/4} · c = 9.55×10⁻¹⁹ м
r₀ = 1.0 м :  c·τ_legal = 3.02×10⁻¹⁸ м
```

Это **ровно** шкала закрытия разрыва из `GAP_CLOSURE.md`:
`a_крит = 0.766·√(l_P·r₀) = 9.74×10⁻¹⁹ м` (r₀=0.1 м). То есть два
независимых расчёта сходятся на одном размере: **атометр** (10⁻¹⁸ м).

Совпадение не случайно: `a_крит` — это минимум зазора, при котором энергия
Казимира догоняет ρ_need, и одновременно максимум «легальной» длины
экспозиции по QI. На масштабе ~10⁻¹⁸ м проверяемая физика достигает ровно той
границы, где разрешён портал-проход для квантовых носителей.

## 2. Источник минус-давления (вектор ρ_EW)

Электрослабый вакуум (VEV Хиггса v = 246 ГэВ):

```
ρ_EW = v⁴/(ħc)³ = 7.64×10⁴⁶ Дж/м³
```

| r₀ | ρ_need | ρ_EW/ρ_need |
|---|---|---|
| 0.1 м | 4.8×10⁴⁴ | **159×** |
| 1.0 м | 4.8×10⁴² | **15860×** |
| 1.26 м (предел) | 3.0×10⁴² | 1.0× |

Энергия EW-вклада покрывает порталы-горловины вплоть до r₀ ≈ 1.26 м —
человеческий масштаб. Но см. §3: наличие нужной массы энергии ещё не значит,
что её можно сосредоточить так, чтобы QI было соблюдено.

## 3. Вердикт по триадной классификации

### СВЕТ — **РАЗРЕШЕНО, строим сейчас**
Фотон не проводит время в области отрицательной энергии (τ→0), квантовое
неравенство не ограничивает свет. «Световой мост» и реле из линз Френеля —
физически честное устройство (см. `JUNK_PORTAL.md`).

### КВАНТОВЫЙ НОСИТЕЛЬ на атометровой щели — [ПОСТУЛАТ], ровно на границе
При щели a ≈ 10⁻¹⁸ м и окне τ = 3.2×10⁻²⁷ с:
`|ρ|_max(QI) = 4.7×10⁴⁴ ≈ ρ_need(0.1 м) = 4.8×10⁴⁴` (запас 0.98).

Квантовое неравенство **не запрещает** такую структуру — она лежит на
границе легальности. Требуется «инженерия доменов на электрослабой шкале»
(энергии 100–250 ГэВ): это на 28 порядков ближе, чем планковская шкала.
Доступ к щели 10⁻¹⁸ м ни коллайдер, ни лаборатория 2026 года не дают —
потому [ПОСТУЛАТ], а не [ФИЗИКА].

### ЧЕЛОВЕК/МАКРООБЪЕКТ — **ЗАПРЕЩЕНО доказанным QI**
Транзит человека занимает τ ≈ L/c ≈ 6 нс. За это окно QI разрешает
`|ρ| ≤ 3.8×10⁻²⁹ Дж/м³`, а горловине нужно `4.8×10⁴²`. Разрыв
**~1.3×10⁷¹** (71 порядок). Это не «невозможно», а — по существующим
доказанным границам квантовой теории поля — **исключено**, независимо от
материала, мусора или подхода к доставке импульсами.

Импульсная упаковка (короткие всплески EW-длительности 3×10⁻²⁷ с, каждый с
пиковой плотностью 7.6×10⁴⁶) не спасает: интеграл Форда–Романа берётся по
мировой линии КРЕСТЯЩЕГОСЯ, а не по одиночному импульсу, поэтому вклад
суммируется по времени дрейфа ~6 нс и усредняется с положительной энергией в
том же окне — итог ниже границы не выходит физически.

## 4. Что это значит для проекта

```
JUNK_PORTAL  ->  СВЕТ: да (линзы Френеля, оверхед)     [ФИЗИКА]
             ->  МАТЕРИЯ: [ПОСТУЛАТ] на атометре        [квант]
             ->  ЧЕЛОВЕК/тело: запрещено QI, ~71 поряд  [ФИЗИКА, теорема]
```

«Настоящий портал» для тела в смысле Рика не противоречит физике как
ОБЩЕЙ цели — физика оставляет ровно один легальный канал: атометровую
электрослабовакуумную щель для квантовых носителей. Этот канал — настоящий
измеримый шаг (Казимир в 1–10 нм → ENZ-усиление плотности мод → коллайдерная
метрия EW-масштаба), но собрать его из подручного хлама нельзя: не хватает
~35 порядков по энергии доступа.
