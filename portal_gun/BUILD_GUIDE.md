# ПОРТАЛ-ПУША: ГАЙД ПО СБОРКЕ

## Версия 1.0 — «Световой мост» (РЕАЛИЗУЕМО СЕЙЧАС)

### Что это
Работающее устройство, которое создаёт зелёный светящийся круг-портал,
внутри которого видна реальная картинка с другой точки (точка соединения).
Выглядит как портал Рика, «видит сквозь», но пройти через него нельзя.

### Состав (все компоненты покупаются готовыми)

| # | Компонент | Спецификация | Цена |
|---|---|---|---|
| 1 | Проектор-часть A | Лазерный проектор, 532 нм (зелёный), 5000 лм | 200 000 ₽ |
| 2 | Камера B | Высокоскоростная камера (120 fps), HDR | 80 000 ₽ |
| 3 | Метаматериальный экран | Круглая плёнка-линза Френеля, D=60 см | 15 000 ₽ |
| 4 | Контроллер | Raspberry Pi 5 / Jetson Orin | 50 000 ₽ |
| 5 | Кольцевой плазмококон | Кольцевой токовый плазмотрон (эффект «зелёного огня») | 40 000 ₽ |
| 6 | Канал связи | WiFi 6E / 5G / оптоволокно (КМГ-кабель) | 10 000 ₽ |
| 7 | Аккумулятор | Li-Po 48В 20Ач (~1 кВт·ч) | 35 000 ₽ |
| 8 | Контроллер ПО | `portal_light_bridge.py` (готово, протестировано) | 0 ₽ |

**Итого: ~430 000 ₽**

### Принцип работы
```
[ПОРТАЛ A]               [ПОРТАЛ B]
 
 Камера ──┐               камера ──┐
         │  КАБЕЛЬ/WiFi         │
 Проектор└──► экран ─────────┘  проектор
          ▲ (видит сцену B)       ▲ (видит сцену A)
```

1. Каждый портал — круглый экран с линзой Френеля
2. Камера портала A снимает сцену перед собой
3. Сигнал передаётся на проектор портала B по кабелю
4. Портал B показывает живое изображение сцены A
5. Кольцевой плазмотрон создаёт зелёное свечение по краю

### Взаимность
Два устройства «смотрят друг на друга». Портал A показывает, что видно
из портала B, и наоборот. Наблюдатель видит сквозь круг актуальную
картинку другой точки.

### Ограничение ВЕРСИИ 1.0
Пройти нельзя — только свет. Это честное ограничение: для прохода
материи нужна версия 2.0 (см. раздел «Версия 2.0»).

## Версия 2.0 — «Настоящий проход» (ТРЕБУЕТ ФИЗИКИ)

### Почему нельзя сейчас
Для прохода материи нужна отрицательная энергия плотностью
ρ = 4.82×10⁴⁴ Дж/м³ в горловине радиусом 0.1 м.

Казимир-эффект даёт ρ_К = π²ħc/(720·a⁴). Чтобы достичь ρ_нужно,
расстояние между пластинами должно быть:

```
a = 9.7×10⁻¹⁹ м ≈ 1 аттометр (10⁻¹⁸ м)
```

Современная литография делает структуры ~3×10⁻⁹ м (3 нм).
Дефицит: 10³⁷ раз в масштабе длины.

### Что нужно для сборки версии 2.0
1. **Полость Казимира с зазором a < 10⁻¹⁸ м** — технология не существует.
   Это [ПОСТУЛАТ], если нет нового физического механизма.
2. **Метаматериальный усилитель** отрицательной энергии (Q ~ 10¹⁰).
   Инженерно реализуемо в СВЧ-диапазоне (сверхпроводники).
3. **Источник ~1 ТВт** (микрореактор / аннигиляция антиматерии).

### Теоретический расчёт (при условии РЕШЕНИЯ пункта 1)

| Величина | Значение |
|---|---|
| Радиус горловины r₀ | 0.1 м |
| ρ_нужно | 4.82×10⁴⁴ Дж/м³ |
| ρ_Казимир при a=10⁻¹⁸ м | 3.5×10⁴⁹ Дж/м³ ✓ |
| КН-предел (пик) | 4.26×10¹⁶² Дж/м³ ✓ |
| Длительность импульса | 5.4×10⁻⁴⁴ с |
| Скважность | 1.6×10⁻³⁴ |
| Мощность | ~10¹² Вт |

## ЗАПУСК ПО (тест без железа)
```bash
# терминал 1 — узел A (слушатель)
python3 portal_light_bridge.py --simulate --role A --port 9100

# терминал 2 — узел B (подключается)
python3 portal_light_bridge.py --simulate --role B --peer 127.0.0.1 --port 9100
```
Проверено: оба узла подключаются, «МОСТ АКТИВЕН», обмен кадрами идёт.
Для видео-захвата нужен `pip install opencv-python-headless`.
